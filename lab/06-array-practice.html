Lab 06 · Array Practice: 40 Problems

Counting, searching, frequency, duplicates, merging, rotation and sorting, each with sample input and output.

How to use this page. Read the problem and the sample input and output, write your own program first, then open the solution. Every solution is a real run of the C code compiled with GCC: press Next ▶ (or the → key) to execute one line at a time and watch the variables, the stack and the console. Some programs have more than one input; try each.
