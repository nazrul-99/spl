Decision-making statements

C provides four ways to change the order in which statements run: the if statement (with its else, nested and ladder forms), the switch statement, the conditional operator ?: (Lecture 02) and the goto statement. In each case a test expression is evaluated; any non-zero value means true and zero means false.

De Morgan's rule


Positive logic is easier to read than negated logic. De Morgan's rule removes a ! in front of a compound condition: negate each operand and swap && with ||. Keep the grouping: !(x && y || !z) is !((x && y) || !z), which becomes (!x || !y) && z.

The else-if ladder


A ladder tests conditions one after another and runs the block of the first true condition; the rest are skipped. It reads better than deeply nested ifs for multi-way decisions such as colour codes or grades. The slide compares the two for the same colour-code task:




else-if ladder
if (code == 1)
    colour = "RED";
else if (code == 2)
    colour = "WHITE";
else if (code == 3)
    colour = "BLUE";
else
    colour = "GREEN";


nested if-else, same logic
if (code != 1)
    if (code != 2)
        if (code != 3)
            colour = "GREEN";
        else
            colour = "BLUE";
    else
        colour = "WHITE";
else
    colour = "RED";




Both give the same answer for every code, but the ladder lists the cases in a natural order and is easier to extend.






Try the input 5, 5, 5. No condition is true, so max is never assigned and the program prints a garbage value (look at max in the memory panel at the start). Ending the ladder with a plain else max = num3; fixes it.



The switch statement


switch compares one integer expression with a list of case constants and jumps to the matching one. Case values must be unique constants; default is optional and runs when nothing matches. break leaves the switch. Without it, execution falls through into the next case.







The goto statement


goto label; branches unconditionally to the statement marked label: in the same function. A label is a valid identifier followed by a colon. The jump can go forward (skipping statements) or backward (repeating them):




Forward jump
goto label;
  ......
  ......
label:
statements;


Backward jump
label:
statements;
  ......
  ......
goto label;




goto makes programs hard to follow, so structured programs avoid it; loops and break do the same jobs more clearly.

E1Indentation does not make a block
Easy Predict the output CO4 · BCL L-4 Analyze
The indentation suggests that both printf calls belong to the if. What is really printed?
#include <stdio.h>
int main()
{
    int x = 5;
    if (x > 10)
        printf("A");
        printf("B");
    printf("C\n");
    return 0;
}
Hint
Without braces, an if controls exactly one statement.
Solution
Output: BC. Only printf("A") belongs to the if; it is skipped because 5 > 10 is false. printf("B") runs regardless of its indentation. Put braces around both statements if both should depend on the test.
E2= instead of ==
Medium Predict the output CO4 · BCL L-4 Analyze
The programmer meant to test whether x equals 3. What happens instead?
#include <stdio.h>
int main()
{
    int x = 0;
    if (x = 3)
        printf("yes %d\n", x);
    else
        printf("no\n");
    return 0;
}
Hint
An assignment is an expression whose value is the value assigned.
Solution
Output: yes 3. x = 3 stores 3 in x, and the value of the whole expression is 3, which is non-zero, so the test is always true. The intended test is x == 3. GCC warns with -Wall: suggest parentheses around assignment used as truth value.
E3Where does the switch stop?
Medium Predict the output CO4 · BCL L-4 Analyze
What does this print for n = 2?
#include <stdio.h>
int main()
{
    int n = 2;
    switch (n)
    {
    case 1:
        printf("one ");
    case 2:
        printf("two ");
    case 3:
        printf("three ");
        break;
    default:
        printf("other ");
    }
    printf("\n");
    return 0;
}
Hint
Execution starts at the matching case and continues until a break or the end of the switch.
Solution
Output: two three . Case 2 matches; there is no break after it, so execution falls through into case 3, whose break ends the switch. default is not reached.

E7Every good student gets a D
Hard Find the bug CO4 · BCL L-4 Analyze
This ladder should give A for 80 and above, B for 60–79, D for 40–59 and F below 40. A student with 85 gets D. Why?


if (marks >= 40)
    grade = 'D';
else if (marks >= 60)
    grade = 'B';
else if (marks >= 80)
    grade = 'A';
else
    grade = 'F';
Hint
A ladder stops at the first true condition. Which condition is first true for 85?
Solution
85 >= 40 is already true, so the first branch runs and the rest is skipped. The B and A branches can never be reached. Test from the highest band down.
