Character Arrays and Strings

A character is a small integer, and a string is an array of characters that ends with the null character '\0'. Most string bugs come from forgetting that last cell.

Practise in the lab: Lab 07 · Strings

Characters are stored as numbers

A character is stored as an 8-bit (1-byte) integer. Which integer depends on the character set; almost every computer uses ASCII (the other historical set is EBCDIC, used on IBM mainframes). char num = 1; and char num = '1'; are different: the first stores the number 1, the second stores the ASCII code of the digit one, which is 49.

char num = 1;
0000 0001
value 1
char num = '1';
0011 0001
value 49, the code for the character '1'

The ASCII table

Click a character to see its code in decimal, binary and hexadecimal.

Useful facts: 'A'–'Z' are 65–90, 'a'–'z' are 97–122, so lowercase = uppercase + 32. '0'–'9' are 48–57, so c - '0' turns a digit character into its value.

Because characters are numbers, they can be compared: ch >= 'A' && ch <= 'Z' is the same test as ch >= 65 && ch <= 90, and easier to read.

Strings and the null character

A string in C is an array of characters ending with the null character '\0' (value 0). A string constant is written in double quotes: char color[6] = "green"; stores the five letters and the '\0', so the array needs length + 1 cells. Writing the characters one by one gives the same array: char color[] = {'g', 'r', 'e', 'e', 'n', '\0'};.

Too small. char my_drink[3] = "tea"; leaves no room for '\0'. MSVC rejects it (error C2117: array bounds overflow); GCC accepts it silently and the array is then not a proper string. Declare char my_drink[4] = "tea";.

Walking a string until '\0'

Loops over strings stop at the null character instead of using a fixed count.

String input and output

FunctionWhat it does
scanf("%s", str)reads one word: stops at the first space, tab or newline. No &, because an array name is already an address.
gets(str)reads a whole line with spaces. It cannot know the array size, so long input overflows it. Removed from C11; avoid it.
fgets(str, size, stdin)reads a line, at most size − 1 characters, and keeps the '\n'. The safe choice.
printf("%s", str), puts(str), fputs(str, stdout)print a string; puts adds a newline, fputs does not.

String conversion: atoi and atof

<stdlib.h> converts digit strings into numbers. atoi (to int) and atof (to double) skip leading spaces, read an optional sign and digits, and stop at the first character that cannot belong to a number.

E1sizeof versus strlen

Easy Predict the output CO4 · BCL L-4 Analyze

What is printed?

#include <stdio.h>
#include <string.h>
int main()
{
    char s[] = "SEU CSE";
    printf("%d %d %c %c\n", (int)sizeof(s), (int)strlen(s), s[4], s[3] == ' ' ? 'Y' : 'N');
    return 0;
}
Hint

sizeof counts the whole array including '\0'; strlen counts characters before '\0'.

Solution

Output: 8 7 C Y. "SEU CSE" has 7 characters, and the array has room for those plus '\0', so 8 bytes. s[4] is 'C' (S, E, U, space, C …) and s[3] is the space.

E2Cutting a string short

Medium Predict the output CO4 · BCL L-4 Analyze

What does this print?

#include <stdio.h>
#include <string.h>
int main()
{
    char s[] = "hello";
    s[2] = '\0';
    printf("%s %d\n", s, (int)strlen(s));
    return 0;
}
Hint

printf("%s") and strlen both stop at the first '\0'.

Solution

Output: he 2. Writing '\0' into s[2] ends the string after "he". The letters "lo" are still in memory (watch the cells in the trace), but every string function stops before them.

E7A copy that prints garbage

Medium Find the bug CO4 · BCL L-4 Analyze

This hand-written copy sometimes prints the right text followed by strange characters. Why?

char src[] = "SEU", dest[10];
int i;
for (i = 0; src[i] != '\0'; i++)
    dest[i] = src[i];
printf("%s\n", dest);
Hint

Which character stops the loop, and is that character ever copied?

Solution

The loop stops at '\0' without copying it, so dest has no terminator. printf keeps reading whatever garbage follows in dest until it happens to meet a zero byte. Add dest[i] = '\0'; after the loop (or use strcpy, which copies the terminator).
