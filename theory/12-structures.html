Structures

A structure groups related values of different types under one name, such as a student's name, ID and major. It is the user-defined data type of C.

A type of your own

So far every variable used a built-in type such as int, double or char. A structure is a derived data type that collects related data items, called members (or components), which need not have the same type. An array holds many values of one type; a structure holds values of different types that belong together.

Declaring the type 
struct student          /* structure tag */
{
    char name[50];      /* members */
    int studentID;
    char major[20];
};
Declaring variables of that type 
struct student my_student;

/* or both at once: */
struct student
{
    char name[50];
    int studentID;
    char major[20];
} my_student;

A variable declaration needs the keyword struct, the tag, the variable names separated by commas, and a semicolon. The type declaration itself reserves no memory; each variable does.

What a structure looks like in memory

The members are stored in the order they are declared. The compiler may insert unused padding bytes so that each member starts at an address suited to its type (an int at a multiple of 4, a double at a multiple of 8). So sizeof a structure can be larger than the sum of its members. The sizes and offsets below were measured with GCC on 64-bit Linux.










Accessing members: the dot operator


Each member is reached with the component selection operator .: my_student.name, my_student.studentID, my_student.major. A member is an ordinary variable of its own type, so my_student.studentID = 10179; and scanf("%d", &my_student.studentID); work as usual.


A structure can be initialised in its declaration, values in member order: struct student my_student = {"Ahmad", 10179, "IT"};.







Nested structures


A member can itself be a structure. With struct address { int houseNumber; char street[20]; int zipcode; }; the student type can hold a whole address:


struct student
{
    char name[50];
    int studentID;
    char major[20];
    struct address addr;
};




Build an access path. CQ from the slides: to store the full record of a student called Tom, declare struct student Tom; (not struct address Tom;, which holds only an address).

typedef: a shorter name


typedef creates a synonym (alias) for an existing type. After typedef struct student StudentData; you can write StudentData my_student; instead of struct student my_student;, including in function parameters: void display(StudentData s1);.





Structures and functions


By value. display(student1); copies the whole structure into the parameter. Changes inside the function affect only the copy. A function can also return a structure, which is copied back to the caller.


By pointer. Read(&student1); passes the address, so the function works on the caller's structure. Through a pointer, members are reached with the arrow operator -> (indirect component selection): s1->id means (*s1).id.


















Input functions. The slides read the name with gets(), which is unsafe and no longer part of C. These versions use scanf("%19s", …), which reads one word of at most 19 characters into the 20-byte array; use fgets(s1->name, 20, stdin) for names with spaces. void main(void) in the slides is also replaced with the standard int main(void).



Copying and comparing


Two variables of the same structure type can be assigned: person1 = person2; copies every member. C has no comparison operators for structures, though:


cmp.c:6:17: error: invalid operands to binary == (have 'struct student' and 'struct student')
    6 |     if (person1 == person2)
      |                 ^~


Compare the members one by one instead: person1.id == person2.id && strcmp(person1.name, person2.name) == 0.

E1Structure assignment copies
Easy Predict the output CO4 · BCL L-4 Analyze
Does changing b change a?
#include <stdio.h>
struct point
{
    int x, y;
};
int main()
{
    struct point a = {2, 3}, b;
    b = a;
    b.x = 10;
    printf("%d %d %d %d\n", a.x, a.y, b.x, b.y);
    return 0;
}
Hint
b = a; copies every member into b's own memory.
Solution
Output: 2 3 10 3. After the copy, a and b are separate structures; changing b.x leaves a.x at 2.
E2Two deposit functions
Medium Predict the output CO4 · BCL L-4 Analyze
Only one of the two deposits reaches the account. Which one, and what is printed?
#include <stdio.h>
struct account
{
    int id;
    float bal;
};
void dep1(struct account a, float m)
{
    a.bal += m;
}
void dep2(struct account *a, float m)
{
    a->bal += m;
}
int main()
{
    struct account s = {1, 100};
    dep1(s, 50);
    dep2(&s, 25);
    printf("%.1f\n", s.bal);
    return 0;
}
Hint
dep1 receives a copy of the structure; dep2 receives its address.
Solution
Output: 125.0. dep1 adds 50 to its own copy, which is lost on return. dep2 works through the pointer (a->bal), so the 25 is added to s.

E7A dot where an arrow belongs
Medium Find the bug CO4 · BCL L-4 Analyze
This function does not compile. Fix it in two different ways.


void show(struct point *p)
{
    printf("(%d, %d)\n", p.x, p.y);
}
Hint
p is a pointer, not a structure.
Solution
GCC reports 'p' is a pointer; did you mean to use '->'?. Members are reached through a pointer with the arrow, p->x, or by dereferencing first, (*p).x. The brackets are required, because . binds tighter than *: *p.x would mean *(p.x).
