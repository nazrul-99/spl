C has no boolean type in the classic sense: a relational or logical operator produces the int 1 for true and 0 for false, and any non-zero value counts as true.

Division and remainder

If both operands of / are integers (int or char), the result is an integer and the fraction is thrown away (truncated toward zero). If either operand is float or double, the result is a floating-point number. % gives the remainder and works only on integers.

Since C99 the quotient is truncated toward zero, so -7 / 2 is -3 and -7 % 2 is -1. The rule (a / b) * b + a % b == a always holds.

Increment and decrement

m++ and ++m both add 1 to m. They differ only when the expression's value is used: postfix gives the old value, prefix gives the new value.

Undefined behaviour. Do not change a variable twice, or change it and read it again, in one expression without a sequence point: i = i++;, a[i] = i++; and printf("%d %d", i, i++); give different results on different compilers. (The slide's a[i++] = 10; is fine: it stores into a[i] and then increments i.)

The conditional operator ?:

exp1 ? exp2 : exp3 evaluates exp1; if it is non-zero the value is exp2, otherwise exp3. Only one of exp2 and exp3 is evaluated. x = (a > b) ? a : b; is a one-line version of if (a > b) x = a; else x = b;.

Each left shift by k multiplies by 2k and each right shift divides by 2k, until bits fall off the end: 112 << 2 would be 448, but in 8 bits the top bit is lost and 192 remains. The program uses an unsigned char so the 8-bit behaviour is real.

Common uses: n & 1 is 1 for odd numbers (the lowest bit is set); n | (1 << k) sets bit k; n ^ (1 << k) flips bit k; n << 1 doubles n and n >> 1 halves it.

Brackets matter here. The slide writes if(num & 1 == 1). Because == has higher precedence than &, the compiler reads it as num & (1 == 1), which is num & 1. The answer is right only by coincidence; type it into the evaluator above to see the tree. GCC warns: suggest parentheses around comparison in operand of '&'.

Arithmetic expressions

An expression combines variables, constants and operators according to the syntax of the language: a = b * c; has three operands and two operators (* and =). The number of operands an operator takes is its arity: unary operators take one (-x, !x, ++x), binary operators take two (a + b), and the only ternary operator, ?:, takes three. * / % have higher priority than + -. Algebra written on paper must be rewritten with explicit operators and brackets:

Brackets matter: a + b + c / 2 would divide only c. If a, b and c are integers, (a + b + c) / 2 also truncates; write / 2.0 for a fractional result.

Precedence and associativity

When an expression has several operators, higher precedence binds first. Operators on the same level are grouped by associativity: most go left to right, but unary operators, ?: and assignments go right to left (so a = b = 5 means a = (b = 5)).

Type conversion

In a mixed expression the lower type is converted to the higher type before the operation (implicit conversion). The type conversion hierarchy, from lowest to highest, is char/short → int → unsigned int → long int → unsigned long int → float → double → long double. Going down the ladder against this direction needs a cast. A cast forces a conversion (explicit conversion): (float)num1 / num2 converts num1 first, so the division is done in floating point.

Assigning a wider value to a narrower variable also converts it: int i = 3.99; stores 3 (the fraction is dropped), and char c = 300; keeps only the low 8 bits (44).

E1Integer division, remainder and a cast

Easy Predict the output CO1 · BCL L-2 Understand

What does this program print?

#include <stdio.h>
int main()
{
    int a = 17, b = 5;
    printf("%d %d %d\n", a / b, a % b, -a / b);
    printf("%.2f %.2f\n", (float)a / b, (float)(a / b));
    return 0;
}
Hint

Integer division truncates toward zero. In the last printf, notice where the cast is applied in each expression.

Solution
3 2 -3
3.40 3.00

17 / 5 is 3 and 17 % 5 is 2. -a / b truncates toward zero, giving −3. (float)a / b converts before dividing, giving 3.40; (float)(a / b) divides first (3) and then converts, giving 3.00.

E2Precedence without brackets

Easy Predict the output CO1 · BCL L-2 Understand

Work out the value of each expression by hand, using the precedence table above.

#include <stdio.h>
int main()
{
    int r = 2 + 3 * 4 % 5 - 6 / 4;
    int t = 10 > 5 > 2;
    printf("%d %d\n", r, t);
    return 0;
}
Hint

* / % are done before + -, left to right. A relational operator produces 0 or 1, which can be compared again.

Solution

Output: 3 0.

2 + 3 * 4 % 5 - 6 / 4 → 3 * 4 = 12 → 12 % 5 = 2 → 6 / 4 = 1 → 2 + 2 − 1 = 3.

10 > 5 > 2 is (10 > 5) > 2 = 1 > 2 = 0. It does not mean "5 is between 2 and 10"; that needs 10 > 5 && 5 > 2.

E3Prefix and postfix in expressions

Medium Predict the output CO4 · BCL L-4 Analyze

Give the final values of m, n, x and y.

#include <stdio.h>
int main()
{
    int m = 5, n = 5, x, y;
    x = m++ * 2;
    y = ++n * 2;
    printf("%d %d %d %d\n", m, n, x, y);
    return 0;
}
Hint

Postfix m++ gives the old value to the expression; prefix ++n gives the new one. Both variables end up incremented.

Solution

Output: 6 6 10 12. x = m++ * 2 uses 5 (then m becomes 6), so x = 10. y = ++n * 2 first makes n 6 and uses 6, so y = 12.

E4Short-circuit evaluation

Medium Predict the output CO4 · BCL L-4 Analyze

Does j ever change? What is printed?

#include <stdio.h>
int main()
{
    int i = 0, j = 5, k;
    k = (i != 0) && (++j > 5);
    printf("%d %d\n", k, j);
    k = (i == 0) || (j++ > 100);
    printf("%d %d\n", k, j);
    return 0;
}
Hint

&& stops as soon as the left side is false; || stops as soon as the left side is true. A skipped right side is never evaluated, so its ++ never happens.

Solution
0 5
1 5

In the first expression i != 0 is false, so ++j is skipped. In the second, i == 0 is true, so j++ is skipped. j stays 5. Type both expressions into the evaluator above to see the skipped branches.

E5Bitwise operators on 12 and 10

Medium Predict the output CO1 · BCL L-2 Understand

Write 12 and 10 in binary first, then compute each result.

#include <stdio.h>
int main()
{
    int a = 12, b = 10;
    printf("%d %d %d %d %d\n", a & b, a | b, a ^ b, a << 2, a >> 1);
    return 0;
}
Hint

12 = 1100 and 10 = 1010. Shifting left by 2 multiplies by 4; shifting right by 1 halves.

Solution

Output: 8 14 6 48 6. 1100 & 1010 = 1000 (8); 1100 | 1010 = 1110 (14); 1100 ^ 1010 = 0110 (6); 12 << 2 = 48; 12 >> 1 = 6.

E6Even or odd, positive or not, with ?: only

Easy Write a program CO2 · BCL L-3 Apply

Read an integer and print whether it is even or odd and whether it is positive or not, using the conditional operator instead of if. Input −7 should print -7 is odd and not positive.

Hint

%s can print a string chosen by ?:, for example (n % 2 == 0) ? "even" : "odd".

Solution

For −7, -7 % 2 is −1, not 1, so test n % 2 == 0 rather than n % 2 == 1 when negative numbers are possible.

E7An average that is always a whole number

Hard Find the bug CO4 · BCL L-4 Analyze

For the scores 1, 2 and 2 this program prints Average = 1.00 instead of 1.67. Explain why and fix it.

int a, b, c;
float avg;
scanf("%d%d%d", &a, &b, &c);
avg = (a + b + c) / 3;
printf("Average = %.2f\n", avg);
Hint

Which type does (a + b + c) / 3 have before it is stored in avg?

Solution

All operands are int, so the division is integer division: 5 / 3 = 1. Only then is 1 converted to float for the assignment. Make one operand floating point: (a + b + c) / 3.0 or (float)(a + b + c) / 3.
