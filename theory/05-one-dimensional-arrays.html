One-Dimensional Arrays

An array is a group of consecutive memory cells that share one name and one type. Each element is reached by its index, starting from 0.

Practise in the lab: Lab 05 · Arrays, Lab 06 · Array Practice: 40 Problems

What an array is

An array stores many values of the same type under one name, in consecutive memory locations. Its size is fixed when it is declared and does not change while the program runs. To reach one element, write the array name and the element's position (its index or subscript) in square brackets: c[0], c[1], …, c[11] for int c[12];.

Arrays and structures are structured data types: they hold values that have a structure. Built from them, C programs create the classic data structures (linked lists, stacks, queues and trees) studied in the Data Structures course. In the family of data types, arrays, pointers and functions are derived types and structures, unions and enums are user-defined (see the chart in Lecture 01).

Declaration: data_type array_name[size];, for example int my_array[100];, char name[20];, double bigval[5*200]; or several at once, int a[27], b[10], c[76];.

Indexes and addresses

Declared as int c[12]; with each int taking 4 bytes. Click a cell, or type an assignment.

No bounds checking. C does not check indexes. c[12] is outside the array; writing to it silently overwrites whatever lies next in memory, or crashes the program. Valid indexes are 0 to size − 1.

Initialisation

At compile time, list the values in braces. If there are fewer values than elements, the remaining elements become 0; more values than elements is an error; if the size is left out, the number of values decides it. At run time, use a loop.

Character arrays

char name[10] = "Well Done"; stores nine characters and the compiler adds the null character '\0' in name[9] to mark the end of the string. Always leave one extra element for '\0'. Lecture 07 covers strings in full.

Sorting with bubble sort

Sorting turns an unordered collection into an ordered one: input 25 14 78 5 90 67 32 85, output 5 14 25 32 67 78 85 90. Bubble sort walks through the array comparing neighbours and swapping them when the left one is larger. After one pass the largest value has "bubbled" to the end. Repeating the pass n − 1 times sorts the array.

E1A partly initialised array
Easy Predict the output CO4 · BCL L-4 Analyze
Only two values are given for five elements. What is printed?
#include <stdio.h>
int main()
{
    int a[5] = {4, 8};
    int i;
    for (i = 0; i < 5; i++)
        printf("%d ", a[i] * 2);
    printf("\n");
    return 0;
}
Hint
Elements without an initial value in a braced initialiser become 0.
Solution
Output: 8 16 0 0 0 . a[2] to a[4] are set to 0 by the initialiser, so doubling them still gives 0.
E2Reverse it twice
Medium Predict the output CO4 · BCL L-4 Analyze
The loop is meant to reverse the array. What does it actually print, and why?
#include <stdio.h>
int main()
{
    int a[6] = {1, 2, 3, 4, 5, 6};
    int i, t;
    for (i = 0; i < 6; i++)
    {
        t = a[i];
        a[i] = a[5 - i];
        a[5 - i] = t;
    }
    for (i = 0; i < 6; i++)
        printf("%d ", a[i]);
    printf("\n");
    return 0;
}
Hint
Follow the swaps for i = 0, 1, 2, then for i = 3, 4, 5. Which pairs are swapped in the second half?
Solution
Output: 1 2 3 4 5 6 , unchanged. For i = 0, 1, 2 the loop swaps the pairs (0,5), (1,4), (2,3), which reverses the array. For i = 3, 4, 5 it swaps (3,2), (4,1), (5,0) again, undoing the work. The loop must stop at the middle: for (i = 0; i < 6 / 2; i++).

E7Two bugs in a maximum
Medium Find the bug CO4 · BCL L-4 Analyze
Find both bugs in this function body that should print the largest of n numbers stored in a.


int max = 0, i;
for (i = 0; i <= n; i++)
    if (a[i] > max)
        max = a[i];
printf("Max = %d\n", max);
Hint
Test it in your head with the numbers −8 −3 −12. Also count how many elements the loop visits.
Solution
(1) Starting max at 0 is wrong when every number is negative: the answer would be 0, which is not in the array. Start with max = a[0]. (2) i <= n reads a[n], one element past the end; the value there is garbage and can even become the "maximum". Use i < n.
