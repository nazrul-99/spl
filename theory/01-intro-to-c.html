Introduction to C Programming

What a C program is made of, how the compiler turns it into a running program, and how values of each data type are stored and printed.

Practise in the lab: Lab 01 · Fundamentals, Bitwise and Ternary Operators

Why C

C programs are fast and small because C's data types and operators map almost directly onto what the machine does. C has only 32 keywords; most of its power comes from library functions such as printf() and sqrt(), and you can extend that library with functions of your own.

The slides give an example of the speed difference: counting a variable from 0 to 15000 takes about one second in C but more than 50 seconds in an interpreted BASIC.

C is portable (the same source compiles on Windows, Linux and microcontrollers) and it suits structured programming: a program is split into functions, each with one job, which makes debugging, testing and maintenance easier.

From source file to running program


On Linux the steps are: write hello.c, compile it to an object file with gcc -c hello.c (creates hello.o), link it with the library into an executable with gcc hello.o (creates a.out), and run it with ./a.out. Code::Blocks does the same steps when you press Build and run.

Preprocessor directives start with # and are handled before compilation. #include <stdio.h> pastes in the declarations of the standard input/output functions; #define PI 3.14159 replaces every PI with 3.14159. Execution always starts at main(); a program without main() compiles but fails to link with undefined reference to `main'.


Program life cycle


Writing a program is a loop, not a straight line. A syntax error sends you back to the editor before the program can be linked; a logic or data error (wrong output) sends you back after it runs.




Four ways to write main()




int main(void)
{
    return 0;
}


void main(void)
{
}


main(void)
{
}


main()
{
}




All four appear in textbooks and old compilers accept them. Only int main(void) (or int main()) is standard C: main returns an int to the operating system, 0 meaning success. Leaving out the return type relies on the old "implicit int" rule that C99 removed, and void main is a compiler extension. main is an identifier; do not use the name for anything else. Try it yourself: rename main in a program and read the linker error.

C tokens


The smallest units the compiler reads are tokens. There are six kinds: keywords, identifiers, constants, strings, operators and special symbols. Type any C statement and see how it splits.

Keywords have a fixed meaning and are the building blocks of statements. Constants are fixed values that do not change while the program runs.


Is it a valid identifier?


Identifiers name variables, functions and arrays. Rules: start with a letter or underscore, then letters, digits or underscores only; no spaces; not a keyword; upper and lower case are different. ANSI C guarantees that the first 31 characters are significant.


A variable is a data name for a memory cell; its value may change while the program runs. Choose names that describe the value (total_marks, not x). The slides also advise keeping names to 8 characters, because some old compilers looked only at the first 8.

TypeBytesRange or precisionprintf / scanf


Are long and long long the same? On 64-bit Linux and macOS they happen to be: both are 8 bytes with the same range. They are still different types, and elsewhere they differ. The C standard only guarantees that long has at least 32 bits and long long at least 64 bits. On Windows (Code::Blocks with MinGW, or Visual Studio) long stays 4 bytes, the same as int, while long long is 8. So when a value may exceed about 2.1 billion, use long long, and always print each type with its own specifier: %ld for long, %lld for long long.


Sizes depend on the machine. The slides use a 16-bit machine, where int is 2 bytes and holds −32768 to 32767 (that is −215 to 215−1). Modern compilers use 4-byte int. long is 8 bytes on 64-bit Linux but 4 bytes on Windows (MinGW, used by Code::Blocks). Use sizeof(type) when you need to know.

Characters are small integers. char ME = 'I'; stores the ASCII code 73 in 8 bits: 0100 1001. A character constant goes inside single quotes. The full ASCII table (codes 32–126 with decimal, octal and hexadecimal values) is interactive in Lecture 07.




void has no values; a function of type void returns nothing. typedef gives a type a new name: typedef int marks; marks sub1, sub2;. enum defines named integer constants: enum day {SAT, SUN, MON}; makes SAT 0, SUN 1 and so on.

Input with scanf()


scanf("%f%f", &H, &W); reads two numbers and stores them in H and W. The & (address-of operator) passes the address of each variable, so scanf knows where in memory to put the value. Without &, scanf receives the current (garbage) value instead of a location and the program usually crashes. Lecture 10 explains addresses in detail.

E3A program that reads nothing correctly
Medium Find the bug CO4 · BCL L-4 Analyze
The program should read an age and a CGPA and print them. Find every error.


#include <stdio.h>
int main()
{
    int age;
    float cgpa;
    printf("Enter age and CGPA: ");
    scanf("%d %d", age, &cgpa);
    printf("Age %d, CGPA %.2f\n", age, cgpa);
    return 0;
}
Hint
Look at each argument of scanf(): does it give an address, and does the specifier match the variable's type?
Solution
Two errors, both in scanf: age is passed without &, so scanf receives a garbage value instead of an address (the program usually crashes); and cgpa is a float but is read with %d, which stores integer bits into it. The corrected call is scanf("%d %f", &age, &cgpa);.
E4Seconds to hours, minutes and seconds
Easy Write a program CO2 · BCL L-3 Apply
Read a number of seconds and print it as hours, minutes and seconds. Input 3725 should print 3725 seconds = 1 h 2 m 5 s.
Hint
Integer division and remainder do all the work: one hour is 3600 seconds and one minute is 60.
Solution
Divide by 3600 for hours, take the remainder, then divide that by 60 for minutes; the last remainder is the seconds.
E5Going past the limit
Medium Predict the output CO4 · BCL L-4 Analyze
Each variable is already at the largest value its type can hold. What does the program print? (GCC, 8-bit char, 16-bit short.)
#include <stdio.h>
int main()
{
    char c = 127;
    unsigned char u = 255;
    short s = 32767;
    c = c + 1;
    u = u + 1;
    s = s + 1;
    printf("%d %d %d\n", c, u, s);
    return 0;
}
Hint
Use the "See the bits" tool above: add 1 to the largest value of each type and see where the bit pattern lands.
Solution
Output: -128 0 -32768. 127 + 1 needs 8 bits that read as −128 in a signed char; 255 + 1 wraps to 0 in an unsigned char; 32767 + 1 becomes −32768 in a short. Unsigned wrap-around is defined by the C standard; for the signed types the result is implementation-defined and GCC wraps.

E7Swap without a third variable
Hard Write a program CO2 · BCL L-3 Apply
Read two integers and swap them using only arithmetic, without a temporary variable. Print the values before and after.
Hint
After a = a + b; the sum holds both values. How can you get the old a back out of it?
Solution
a = a + b; b = a - b; a = a - b;. After the first line a holds the sum; subtracting the old b gives the old a, and so on. Watch both variables change in the memory panel. A limitation to mention in an exam answer: if the sum exceeds the int range the method overflows, so the temporary-variable swap is safer in real programs.
