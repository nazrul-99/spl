Two-Dimensional Arrays

A two-dimensional array is a table of rows and columns, a matrix. It is stored in memory row after row, and nested loops visit its cells.

Practise in the lab: Lab 05 · Arrays

Declaring and indexing

Use two pairs of square brackets: the first gives the number of rows, the second the number of columns. int values[3][4]; creates a table of 3 rows and 4 columns. nums[1][3] means row 1, column 3. Once both indexes are given you are working with a single int, so assignment works as usual: nums[2][3] = 72;.

How a 2D array sits in memory

Memory is one long line of bytes, so C stores the rows one after another (row-major order). Hover or tap a cell of nums (the array from the slides) to see where it lives.

Memory, one int (4 bytes) per box, base address 2000

This is why initialisation also goes in row order. All three forms below create the same array; the first is the clearest.

int nums[3][4] = { {8, 16, 9, 52},
                   {3, 15, 27, 6},
                   {14, 25, 2, 10} };

int nums[3][4] = { 8, 16, 9, 52,
                   3, 15, 27, 6,
                   14, 25, 2, 10 };

int nums[3][4] = {8, 16, 9, 52, 3, 15, 27, 6, 14, 25, 2, 10};

To visit every cell you need nested loops: the outer loop chooses the row, the inner loop walks along its columns.

Matrix operations, step by step

Edit the matrices (one row per line, numbers separated by spaces) and choose an operation. Addition and subtraction need matrices of the same dimensions. Multiplication needs the number of columns of A to equal the number of rows of B; an m × n matrix times an n × p matrix gives an m × p matrix, and each cell is a row of A times a column of B.

E1Reading cells by index
Easy Predict the output CO4 · BCL L-4 Analyze
What is printed?
#include <stdio.h>
int main()
{
    int m[2][3] = {{1, 2, 3}, {4, 5, 6}};
    printf("%d %d %d\n", m[1][0], m[0][2], m[1][2] - m[0][1]);
    return 0;
}
Hint
The first index is the row, the second the column, both from 0.
Solution
Output: 4 3 4. m[1][0] is the first element of the second row (4); m[0][2] is 3; m[1][2] - m[0][1] is 6 − 2 = 4.
E2Both diagonals
Medium Predict the output CO4 · BCL L-4 Analyze
The matrix is initialised in row order without inner braces. What is printed?
#include <stdio.h>
int main()
{
    int m[3][3] = {1, 2, 3, 4, 5, 6, 7, 8, 9};
    int i, s = 0;
    for (i = 0; i < 3; i++)
        s += m[i][i] + m[i][2 - i];
    printf("%d\n", s);
    return 0;
}
Hint
Fill the 3 × 3 grid row by row first. m[i][i] is the main diagonal, m[i][2 - i] the other one.
Solution
Output: 30. The rows are 1 2 3 / 4 5 6 / 7 8 9. The main diagonal is 1 + 5 + 9 = 15 and the anti-diagonal 3 + 5 + 7 = 15. The centre 5 is counted twice, giving 30.

E6Transpose a square matrix in place
Hard Write a program CO3 · BCL L-3 Apply
Transpose an n × n matrix without a second array: after the program, m[i][j] must hold what m[j][i] held before.
Hint
Swap m[i][j] with m[j][i], but only for j > i. What would happen if the inner loop ran over every j?
Solution
Swapping every pair twice would put each value back (the same trap as reversing an array twice in Lecture 05). Restricting to j > i swaps each pair once and leaves the diagonal alone.
E7Matrix product that keeps growing
Medium Find the bug CO4 · BCL L-4 Analyze
For A = [[2, −1], [3, 4]] and B = [[3, −9, 2], [5, 7, −6]] the first row of the result should be 1 −25 10, but this code prints 1 −24 −14. Why?


sum = 0;
for (i = 0; i < rowsA; i++)
    for (j = 0; j < columnsB; j++)
    {
        for (k = 0; k < columnsA; k++)
            sum += A[i][k] * B[k][j];
        C[i][j] = sum;
    }
Hint
Where is sum set back to zero?
Solution
sum = 0; runs once, before all the loops, so every cell adds onto the total of the cells before it: C[0][1] = 1 + (−25) = −24 and C[0][2] = −24 + 10 = −14. Move sum = 0; inside the j loop, just before the k loop, so each cell starts from zero.
