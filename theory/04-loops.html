Decision Making and Looping

A loop repeats a block while a condition holds. Watch the four parts of every loop (initialise, test, body, update) run in order, then use nested loops to draw patterns.

Practise in the lab: Lab 03 · Loops and Star Patterns, Lab 04 · Loop Practice: 30 Problems

The looping process

Every loop has four parts: (1) initialise a control variable, (2) test it, (3) run the body, (4) update the control variable, then go back to the test. Each pass is called an iteration. C provides three loops: while and for test before the body (entry-controlled), do … while tests after it (exit-controlled), so its body runs at least once.

A loop therefore has two segments: the body and the control statement (the test).

The while loop


while (test condition) { body } runs the body as long as the condition is true. When it becomes false, control continues after the loop. The slide's example sums 1 to 100.





The do … while loop


do { body } while (test condition); runs the body first and tests afterwards. Note the semicolon after the closing bracket. It suits input that must be read at least once, such as "keep reading until the user types 0 or a negative number".

The for loop


for (initialization; test-condition; increment) { body } puts all loop control in one line. It is the natural choice when the number of iterations is known in advance (a counter-controlled loop).




Additional features of for

    

  • Several variables, separated by commas: for (p = 1, n = 9; n < 17; n++) and for (n = 9, m = 50; n < m; n++, m--).
    • 

  • A compound test: for (i = 50; i < 100 && sum < 1000; ++i).
    • 

  • Expressions in the initialisation and update: for (x = (m + n) / 2; x > 0; x = x / 2).
    • 

  • Any part may be empty: for ( ; M != 100 ; ) { M += 5; }. With all three empty, for ( ; ; ) is an infinite loop.

Counter-controlled and sentinel-controlled loops


A counter-controlled (definite) loop runs a known number of times. A sentinel-controlled (indefinite) loop runs until a special value, the sentinel, appears in the data, for example −1 marking the end of the marks.





Nested loops and patterns


A loop inside another loop runs completely for every iteration of the outer one: the outer test (condition 1) is checked, then the inner loop runs its own test (condition 2), body and update until condition 2 is false, and only then does the outer update run. In pattern programs the outer loop picks the row and the inner loops print the spaces and stars of that row.

Jumps in loops: break and continue


break leaves the loop immediately; the program continues after it. continue skips the rest of the current iteration and goes on with the next one (to the update in a for, to the test in a while).

#include <stdio.h>
int main()
{
    int i;
    for (i = 1; i <= 10; i += 3)
        printf("%d ", i);
    printf("| %d\n", i);
    return 0;
}
Hint
The loop ends when the test fails, so i keeps the first value that failed the test.
Solution
Output: 1 4 7 10 | 13. After printing 10, i becomes 13; 13 <= 10 is false, so the loop ends with i = 13.
E2continue and break together
Medium Predict the output CO4 · BCL L-4 Analyze
Trace the loop and give the final i and s.
#include <stdio.h>
int main()
{
    int i = 0, s = 0;
    while (i < 10)
    {
        i++;
        if (i % 2 == 0)
            continue;
        if (i > 7)
            break;
        s += i;
    }
    printf("%d %d\n", i, s);
    return 0;
}
Hint
Make a table with columns i, "skipped?", "stopped?" and s. Remember that i is incremented at the top of the body.
Solution
Output: 9 16. Even values of i are skipped by continue; the odd values 1, 3, 5, 7 are added (s = 16). At i = 9 the test i > 7 is true and break leaves the loop before 9 is added.

E7A sum that comes out as 6
Hard Find the bug CO4 · BCL L-4 Analyze
This should print the sum 1 + 2 + 3 + 4 + 5 = 15, but it prints 6. Find the bug.


int i, sum = 0;
for (i = 1; i <= 5; i++);
    sum += i;
printf("%d\n", sum);
Hint
Look at the end of the for line.
Solution
The semicolon after for (…) is an empty statement, and that empty statement is the whole loop body. The loop just counts i up to 6, and then sum += i; runs once with i = 6. Remove the semicolon. The buggy version is traced first so you can see the loop finish before the addition.
